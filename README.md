## 📌 Project Overview

**EduROOM** is a classroom reservation and scheduling system designed for **Academic Building IV of Camarines Sur Polytechnic Colleges (CSPC)**.

It replaces manual reservation workflows with a secure, automated, real-time platform — deployed and hosted on **Microsoft Azure**.

### The system provides:
- Real-time room availability viewing
- Faculty reservation submission and tracking
- Administrative approval dashboard
- User account management with role-based access
- Activity logging and analytics dashboard
- Secure authentication and session controls
- WebSocket-based real-time notifications

### Tech Stack:
| Layer | Technology |
|-------|------------|
| Frontend / UI | Python + Flet |
| Backend | Python |
| Database | Azure SQL Database for MySQL |
| Real-Time | WebSockets |
| Hosting | Microsoft Azure App Service |
